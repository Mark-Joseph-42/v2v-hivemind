2.5 cav_demo/v2v_network.py
----------------------------------------------------------------------------------------------------
* Primary Lead: Sanjana M Paul
* File Type   : Distributed V2V Mesh Network Simulator
* Purpose     : Simulates a decentralized, wireless ad-hoc vehicle-to-vehicle communication network,
                extracting 11D kinematic packets, modeling transmission noise, and propagating emergency alerts.
* Key Classes & Methods:
  - V2VPacket (dataclass):
      Contains: sender_id, display_name, step, pos (x, y), velocity (vx, vy), speed_kmh,
      heading_rad, yaw_rate, steering, throttle, is_braking flag, lane_index,
      11D kinematic NumPy vector, latency_ms, and dropped status flag.
  - V2VNetworkMesh:
      * extract_kinematics(agent_id, vehicle, step, last_action):
          Extracts position, velocities, Bullet chassis yaw rate, steering, and throttle.
          Constructs the 11D continuous state array (float32).
          Samples stochastic latency from normal distribution: N(mu=12ms, sigma=6ms).
          Simulates packet drop via Bernoulli trial: P(drop) = 0.02.
      * broadcast_step(agents_dict, step, actions_dict):
          Simulates a round of wireless broadcast over an ad-hoc geometric graph G = (V, E).
          Iterates pairwise between vehicles; establishes communication link if Euclidean distance
          d <= comm_radius_m (80.0m). Non-dropped packets are appended to receiver's history queue.
      * get_emergency_brake_warnings(receiver_id, max_distance, only_in_front):
          Scans latest known states for braking neighbors within warning radius (30m).
          Applies 2D vector projection to ensure hazard is ahead of receiver along vehicle heading:
            long_dist = dx * cos(heading) + dy * sin(heading)
            Filters out vehicles behind (long_dist < -2.0m).
      * get_aggregate_stats():
          Computes rolling average latency, total broadcasts, total drops, and packet loss rate.
* Traditional CS Concepts:
  - Data Structures: Bounded FIFO double-ended queues (collections.deque(maxlen=25)) ensuring O(1)
    insertion and oldest-element eviction without dynamic list reallocations.
  - Geometric Random Graph: Dynamic edge generation based on spatial proximity threshold (R = 80m).
  - Stochastic Modeling: Gaussian noise generator (random.gauss) and Bernoulli trials.
  - Computational Geometry: 2D dot product vector projection for directional field-of-view filtering.
  - Time Complexity: O(N^2) pairwise broadcast check per step (bounded, N <= 32).

2.6 cav_demo/collaborative_perception.py
----------------------------------------------------------------------------------------------------
* Primary Lead: Sanjana M Paul & Ritu Franklin
* File Type   : Cooperative Beyond-Line-of-Sight (BLOS) Perception Engine
* Purpose     : Implements Beyond-Line-of-Sight perception (ETSI TR 103 562 / SAE J3186 standard)
                by unmasking obstacles hidden inside the ego vehicle's LiDAR occlusion shadow using
                neighboring CAV sensor data shared over the V2V mesh.
* Key Functions & Classes:
  - is_line_blocked(p_from, p_to, obstacles, vehicle_width=2.4):
      Computes analytical line-segment obstacle intersection. Projects obstacle vector v = (ox-x1, oy-y1)
      onto ray direction vector d = (x2-x1, y2-y1):
        t = (v . d) / ||d||^2
      If 0.08 < t < 0.92 (obstacle lies between endpoints), computes orthogonal distance:
        dist_to_ray = ||v - t*d||
      Returns True if dist_to_ray < (vehicle_width * 0.85).
  - CollaborativePerceptionEngine:
      * update(env, ego_agent_id, v2v_mesh):
          1. Gathers peer CAVs within 80m V2V communication range.
          2. Extracts MetaDrive local LiDAR observation objects for ego and peers.
          3. Identifies targets hidden in ego vehicle's occlusion shadow but observed by peer CAVs.
          4. Performs geometric ray-casting for all civilian traffic and CAVs.
          5. Resolves revealing partner CAV and minimum distance.
      * _render_collaborative_scene(...):
          Dynamically creates 3D visual geometry using Panda3D LineSegs:
            - Electric Cyan Ring: Highlights currently tracked ego vehicle.
            - Radiant Fluorescent Green Rings: Rendered at the 3D ground coordinates of occluded targets.
            - Translucent Green Dashed Links: Drawn between the revealing partner CAV and the hidden target.
* Traditional CS Concepts:
  - Computational Geometry: Ray-casting, vector orthogonal projection, point-to-segment distance.
  - Sensor Fusion: Decentralized Cooperative Perception Message (CPM) unmasking logic.
  - Computer Graphics Pipeline: Direct scene graph manipulation via Panda3D LineSegs geometry nodes.
  - Complexity: O(M * P) vector checks, optimized with spatial distance pruning (d <= 60m) and hash set
    coordinate deduplication (processed_target_keys).

2.7 cav_demo/idm_fleet_policy.py
----------------------------------------------------------------------------------------------------
* Primary Lead: Ritu Franklin
* File Type   : Autonomous Driving Policy with V2V Cooperative Defense
* Purpose     : Manages autonomous car-following and lane-keeping policies for fleet vehicles using
                the non-linear Intelligent Driver Model (IDM), enhanced with V2V hazard deceleration.
* Key Classes & Logic:
  - IDMFleetController:
      * _get_or_create_policy(agent_id, vehicle):
          Lazily instantiates and caches MetaDrive's IDMPolicy(vehicle, seed=42).
      * get_actions(agents_dict, v2v_mesh, manual_agents):
          Computes baseline [steering, throttle] from IDM car-following equations:
            dv/dt = a * [ 1 - (v/v0)^delta - (s*(v, dv) / s)^2 ]
          Cooperative Braking Finite State Machine (FSM):
            If cooperative braking enabled and emergency warning received for a hazard ahead:
              - Proportional Deceleration:
                  dist < 12m  -> throttle = min(throttle, -0.50) (Hard Emergency Deceleration)
                  dist < 25m  -> throttle = min(throttle, -0.15) (Defensive Coasting)
                  dist >= 25m -> throttle = min(throttle, +0.05) (Gentle Speed Matching)
              - Deadlock / Livelock Prevention via Hysteresis:
                  Cooperative braking limited to 15 consecutive steps (~0.75s).
                  Exceeding limit triggers an automatic 12-step cooldown counter (coop_cooldown=12)
                  to prevent permanent fleet freezing and ensure forward progress.
              - Action Clamping: Clamps steer and throttle to [-1.0, 1.0].
      * is_coop_braking(agent_id): Returns boolean status for telemetry HUD indicator.
* Traditional CS & Control Theory Concepts:
  - Non-linear Differential Equations: Numerical approximation of IDM continuous-time ODEs.
  - Control Theory: Proportional deceleration overrides based on spatial separation.
  - Finite State Machine with Hysteresis: Prevents high-frequency control chatter and circular deadlocks.
